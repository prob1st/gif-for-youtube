Yardım ve sorun giderme

  • GIF eklenmiyor: Önce yorum kutusuna tıkla (imleç görünsün), sonra GIF'i ekle. YouTube yorum alanını yeniden oluşturursa paneli kapatıp aç.
  • Kısayollar: Ctrl+Shift+G panel · Ctrl+Shift+Y son GIF · / arama · Esc kapat. Chrome'da chrome://extensions/shortcuts ile değiştirilebilir.
  • Arama boş dönüyor: Giphy'nin ücretsiz API anahtarını buradan alıp aşağıya ekle. Anahtar olmadan arama, hazır paket + web modunda çalışır.
  • GIF gönderdikten sonra kayboluyor: “GIF + link” modunu kullan — GIF ile birlikte kaynak linki de eklenir.
  • Yerel dosyalar: Tarayıcıda kalır (base64), hiçbir sunucuya gönderilmez. Depolama sınırı için 20 tepki sınırı vardır.
